# Dashboard — Secretaria Municipal de Educação

Protótipo mockado (Next.js) para validação com a Dirigente Municipal de Educação.

## Rodar

```bash
cd edu
npm install
npm run dev
```

Abra [http://localhost:3000](http://localhost:3000).

## Telas

| Rota | Tela |
|------|------|
| `/` | Dashboard Executivo |
| `/schools` | Escolas |
| `/active-search` | Busca Ativa |
| `/waitlist` | Lista de Espera |
| `/staff` | Quadro de Pessoal |
| `/students/[id]` | Aluno 360º |

Código em inglês; textos da interface em português. Dados 100% fictícios.
